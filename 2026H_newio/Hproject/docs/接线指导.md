# 引脚接线文档与接线指导

适用项目：2026 TI 电赛 H 题 车载平衡滚球运动控制系统
主控：WHEELTEC C07A 核心板（MSPM0G3507SPTR，**LQFP-48 PT 封装**）+ S28A 底板

本文所有引脚均以 `generated/ti_msp_dl_config.h` 的实际生成结果为准，
连接器归属以 `4.C07A适配S28A底板原理图.pdf` 网表为准。

---

## 0. 安全须知（先读这一段）

1. **先接地，再接电源，最后接信号。** 步进驱动、传感器、K230D 与底板必须共地，
   否则信号电平没有参考点，轻则通信不上，重则烧口。
2. **PA0 / PA1 是本芯片上唯一两个 5V 容忍引脚**（绝对最大 5.5V）。
   其余引脚绝对最大值只有 VDD+0.3V ≈ 3.6V。
   幻尔巡线传感器是 5V 器件，所以 I2C 必须走 PA0/PA1，不要挪到别的脚。
3. **D36A 的 5V 输出不要接到 S28A 的 5V 排针。** S28A 已有自己的 12V→5V 模块，
   两个 5V 源并联会互相灌电流。D36A 与底板之间**只接 GND**。
4. 上电前检查 D36A 接口丝印（丝印在板子背面），电源接反会直接烧驱动。
5. 通电前确认巡线传感器底部没有金属物接触，该板背面引脚裸露，短路会烧板。

## 1. 供电架构

| 供电对象 | 取电位置 | 说明 |
|---|---|---|
| 底板 + 核心板 | 电池 12V → `DC1` → 电源开关 `SW1` → 12V 母线 | 底板自带 12V→5V 模块（`H15`/`H16`） |
| TB6612 电机驱动 | 底板 `H9`/`H12` 已布好 12V + 5V | 不需额外接线 |
| D36A 步进驱动 | 电池 12V，接 D36A 的 `Vin+` / `Vin-` | 可用 D36A 的"输入电源并联输出接口"级联 |
| 幻尔巡线传感器 | 5V，建议取底板 `J4`（5V/GND 排针） | 传感器工作电压 5V，勿接 3V3 |
| K230D | 独立 5V 供电（见 §4.3） | 峰值电流大，不要从底板 5V 取 |
| OLED | 3V3，取底板 `J9`（3V3/GND 排针） | |

D36A 与底板共地：从 D36A 的 `GND` 引一根线到底板任意 GND（`J4`/`J9` 都有 GND）。

## 3. 巡线传感器接线（幻尔 LineFollower，I2C）

### 3.1 接线

传感器板上有一个专用 4 针排针，丝印是 `5V GND SDA SCL`，直接用它最省事。
（板上另有 `5V GND TX RX` 4 针给 UART 用，以及一排 16 针全信号引出，本项目不用。）

| 传感器 | 接到 | 说明 |
|---|---|---|
| 5V | 底板 `J4` 的 5V | **必须 5V**，接 3V3 传感器不工作 |
| GND | 底板 `J4` 的 GND | |
| SDA | PA0 | 5V 容忍脚 |
| SCL | PA1 | 5V 容忍脚 |

上拉电阻：该板是给 Arduino（5V）设计的，板载通常已有上拉到 5V。
若总线读不通，先用示波器看 SDA/SCL 空闲是否为高；确实没有上拉时，
在 PA0/PA1 各加 4.7 kΩ 上拉到 **3V3**（不要上拉到 5V，虽然引脚耐 5V，
但 3V3 上拉已足够满足输入门限，且更安全）。

### 3.2 通信协议（已在 `drivers/line_sensor.c` 实现）

| 项 | 值 | 代码中的宏 |
|---|---|---|
| I2C 地址 | `0x5D` | `HW_LINE_SENSOR_I2C_ADDR` |
| 状态寄存器 | 5，读 1 字节，每位一路 | `HW_LINE_SENSOR_REG_STATE` |
| 模拟值寄存器 | 6，读 N×2 字节，小端 | `HW_LINE_SENSOR_REG_ANALOG` |
| 阈值寄存器 | 22 | `HW_LINE_SENSOR_REG_THRESHOLD` |
| 速率 | 400 kHz | `LINE_I2C_BUS_SPEED_HZ` |

状态字节的位序：厂家例程用 `(temp[0] >> len) & 0x01` 依次打印 `State1..StateN`，
即 **bit0 = 传感器板上的 S1**。S1 在车体的左边还是右边取决于你怎么装板子。

### 3.3 通道数与位序配置

改 `board/board_hardware.h` 两个宏即可，其余代码不用动：

```c
#define HW_LINE_SENSOR_COUNT        (6U)   /* 换 8 路就改成 8U */
#define HW_LINE_SENSOR_BIT0_IS_LEFT (0U)   /* S1 在左边就改成 1U */
```

权重由通道数自动推导：6 路是 ±1/±3/±5，8 路是 ±1/±3/±5/±7。

**重要：传感器出厂需要先做学习校准才能正常识别**，
按板上 `KEY` 键按厂家教程校准一次，否则读回来的状态位全是 0 或全是 1。

## 4. 步进驱动 D36A 接线

### 4.1 控制信号

D36A 的"电机控制输入接口"是两列，**丝印在板子背面**。
左列 `ADC EN2 DIR2 ST2 GND`（第 2 路），右列 `5V EN1 DIR1 ST1 GND`（第 1 路）。
本项目只用第 1 路，接右列：

| D36A | MCU 引脚 | 底板取点 | 说明 |
|---|---|---|---|
| ST1 | PB16 | `J10` | 脉冲输入，**上升沿有效，必须给 PWM** |
| DIR1 | PB17 | `J10` | 方向 |
| EN1 | PA12 | `J10` | **低电平休眠，高电平使能** |
| GND | 底板任意 GND | `J4`/`J9` | 必接，共地 |
| 5V | **不接** | — | 底板已自带 5V 源，见 §0.3 |
| ADC | 不接 | — | 电池电压已由底板 PA15 分压测量 |

`J10` 正好只有这三个信号（PA12 / PB16 / PB17），这也是选它的原因。
同样三个信号也出现在 `U3`（手柄接口，HC-1.25-6PWT），用哪个都行，别同时接。

ST1 只有高低电平是不动的，必须有上升沿——这就是本项目用硬件 PWM
（TIMG7 CC1，占空比 50%）而不是软件翻转引脚的原因。

### 4.2 拨码开关设置

6 位拨码：**1/2/3 设细分，4/5/6 设电流**。
注意厂家真值表里 **1 = 拨到 ON（导通），0 = 断开**，
这是开关位置不是引脚电平（123 带上拉，断开时引脚是高）。

细分（对应代码里的 `STEPPER_MICROSTEPS`）：

| MS1 | MS2 | MS3 | 细分 | 代码应设 |
|---|---|---|---|---|
| 1 | 1 | 1 | 不细分 | 1 |
| 0 | 1 | 1 | 2 | 2 |
| 0 | 1 | 0 | 4 | 4 |
| 1 | 0 | 0 | 8 | 8 |
| **0** | **0** | **0** | **16** | **16 ← 当前代码默认** |
| 1 | 0 | 1 | 32 | 32 |

**当前代码假定 16 细分，所以拨码 1、2、3 三个全部拨到 OFF（断开）。**
若要改细分，同步修改 `drivers/stepper_driver.h`：

```c
#define STEPPER_MICROSTEPS      (16U)   /* 与拨码 1/2/3 保持一致 */
```

电流（4/5/6 = CUR1/2/3），先从最小档试起，够力矩就停：

| CUR1 | CUR2 | CUR3 | 等效电流 |
|---|---|---|---|
| 0 | 0 | 0 | 1.44 A |
| 0 | 0 | 1 | 1.22 A |
| 0 | 1 | 0 | 0.93 A |
| 0 | 1 | 1 | 0.83 A |
| 1 | 0 | 0 | 0.77 A |
| 1 | 0 | 1 | 0.70 A |
| 1 | 1 | 0 | 0.59 A |
| 1 | 1 | 1 | 0.55 A（最小，建议起步档）|

电流越大力矩越大，但发热和耗电也越大。建议 4/5/6 先全拨 ON（0.55 A），
横梁带不动再逐档加。

注意：拨码是**同时设置两路**的，改细分/电流对第 1、2 路一起生效。

### 4.3 电机与电源

- 步进电机用板上"电机A接口"白色 4 pin 排线直插，省去杜邦线。
  42 步进是六线电机，实际只用 `A+ A- B+ B-` 四根。
- `Vin+` / `Vin-` 接电池 12V，注意极性。
- 板载散热风扇默认一直转，别让杜邦线卡进风扇。
- ATD5984 工作时发热正常，别用手直接摸。

## 5. K230D 接线（UART）

### 5.1 接线

| K230D | MCU 引脚 | 说明 |
|---|---|---|
| RX | PB6（MCU TX） | **交叉接**：MCU 发 → K230 收 |
| TX | PB7（MCU RX） | K230 发 → MCU 收 |
| GND | 底板 GND | 必接 |
| 5V / VIN | **独立供电** | 见下 |

PB6/PB7 在底板上是原蓝牙模块座 `H8`（默认焊接）与 `U5`（二选一），
两个座子上都是 `PB6 PB7 GND 5V`。用 `H8` 或 `U5` 都行，取一个。

波特率 115200，8N1，与 `K230_BAUD_RATE` 一致。
电平：K230D 与 MSPM0 都是 3.3V IO，直连即可，不需要电平转换。

### 5.2 供电注意

K230D 跑视觉时瞬时电流不小，**不要从底板 5V 排针取电**，
底板 5V 还要供 TB6612 逻辑和巡线传感器，容易把 5V 拉垮导致主控复位。
建议 K230D 单独用一路 5V（独立降压模块或它自己的 Type-C），
只与底板共 GND。

### 5.3 需要你确认的一点

本地 `相关资料\k230D` 只有元器件手册和封装库，**没有开发板原理图**，
所以我无法确定 K230D 排针上 UART TX/RX 具体是第几脚。
请对着板上丝印找 UART 的 TX/RX（或查正点原子 ATK-DNK230D 在线文档），
接线时记住是**交叉接**。

## 6. 上电调试顺序

按这个顺序做，出问题容易定位：

1. **只接主控 + OLED**，上电。OLED 应显示模式选择界面。
   不亮先查 3V3 和 PA28/PA31/PB14/PB15 四根线。
2. **接巡线传感器**（先不接步进）。传感器板 `PWR` 灯应亮。
   按厂家教程做一次学习校准。
   看 OLED 第 7 行：正常显示每路状态；显示 `------` 说明 I2C 读不通
   （`LineSensor_IsOnline()` 为假），查地址、上拉、接线。
3. 用手在传感器下方移动黑线，确认 OLED 上亮的那一路和实际位置对应。
   **左右反了就把 `HW_LINE_SENSOR_BIT0_IS_LEFT` 取反**，重新编译。
4. **接 D36A**：先只接 GND + EN1 + DIR1 + ST1，**电机先不插**，
   12V 先不上。上电后测 EN1 应为低（代码初始化时 EN 是清零的，驱动开机休眠）。
5. 插电机，上 12V，跑一个低速指令（几百 steps/s）。
   电机不转就用示波器看 ST1 有没有方波；有方波不转就查细分拨码和电流档。
6. **确认方向**：给正的 `Stepper_SetSpeed()`，看横梁往哪边倾。
   与控制律期望的方向相反时，最简单的办法是在 `balance_controller.c` 里
   给 `speed_cmd` 取反，或者把电机 A+/A- 两根线对调。
7. **最后接 K230D**，串口通了再联调整车。

## 7. 代码侧关键约定（接线相关）

| 宏（`board/board_hardware.h`） | 当前值 | 含义 |
|---|---|---|
| `HW_LINE_SENSOR_COUNT` | 6 | 巡线通道数，换 8 路改这里 |
| `HW_LINE_SENSOR_BIT0_IS_LEFT` | 0 | bit0 是否为最左路 |
| `HW_LINE_SENSOR_I2C_ADDR` | 0x5D | 传感器 I2C 地址 |
| `HW_STEPPER_EN_ACTIVE_LEVEL` | 1 | EN 高有效（对应 D36A 高使能） |
| `STEPPER_MICROSTEPS`（`stepper_driver.h`） | 16 | 必须与拨码 1/2/3 一致 |
| `STEPPER_FULL_STEPS_PER_REV` | 200 | 1.8° 步距角 |
| `STEPPER_MAX_FREQ_HZ` | 5000 | 脉冲频率上限，见 §8 |

巡线 I2C 的读取只发生在主循环（`LineSensor_Poll()`，5 ms 一次），
100 Hz 控制中断里的 `LineSensor_Update()` 只对缓存做滤波、不碰总线。
这样传感器掉线或拉长时钟时不会把控制中断卡住。
连续 5 次读失败会退化成"丢线"状态。

## 8. 仍需你在实物上确认的项

这些我在本机无法验证，接线时请一并核对：

1. **K230D 排针 TX/RX 的具体位置** —— 本地资料没有开发板原理图（§5.3）。
2. **六路版传感器的地址与寄存器号** —— 手上文档是 8 路版（`LineFollower_8CH v1.0`），
   地址 `0x5D`、寄存器 5/6/22 来自 8 路版例程。六路版大概率相同，
   读不通时先用 I2C 扫描确认地址。
3. **`H5` 座子的供电电压** —— 底板原理图上该座的电源网络标注我看到的是 3V3，
   但图中该处又画了 5V。**接传感器电源前先用万用表量一下 `H5` 的电源脚**；
   为稳妥起见本文建议传感器 5V 从 `J4` 取，`H5` 只借用 SDA/SCL/GND。
4. **`J10` 三个脚的物理顺序** —— 网表确认 `J10` 就是 PA12/PB16/PB17 三个信号，
   但哪个脚对应哪个信号请照底板丝印确认（丝印图在
   `相关资料\7.S28A底板相关资料\1.S28A底板资料\1.C07A搭配S28A底板丝印图.jpg`）。
5. **`STEPPER_MAX_FREQ_HZ` 的 5 kHz 上限** —— 手册 3.2 节提到 STEP 有具体频率范围，
   我没读到那一页。若手册给的上限不同，改 `stepper_driver.h` 里这个宏。
6. **步进正方向与横梁倾斜方向的对应关系**（§6.6）。
